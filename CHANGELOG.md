## 0.1 (unreleased)

- First build. Request board with transport (air/sea/land), resupply, SITREP and ACE reports.
- Per-kind editors; pickup/delivery filled from own position or map centre.
- Status workflow (draft → sent → acknowledged → approved/denied → in progress → complete/cancelled).
- Map markers: colour by priority, glyph by kind, status dot, dashed ring for exercise/MILSIM.
- Plain-text report on every marker so clients without the plugin can read it.
- Team sync over CoT, last-writer-wins.
- Modes: REAL, EXERCISE, MILSIM, TRAINING.
